# 일본어 조어법

## 형용사 → 부사

[일본어 형용사](notes/일본어/일본어_형용사.md)에서 배운 い형용사/な형용사, 각각 정해진 방법으로 부사(동사를 꾸미는 말)로 바꿀 수 있다.

- い형용사: 어미 い → く
- な형용사: だ를 떼고 に 붙이기

예:
- 早い(はやい, 빠르다) → 早く(はやく, 빨리) — 早く起きます。(빨리 일어납니다.)
- 高い(たかい, 비싸다) → 高く(たかく, 비싸게) — 高く売れました。(비싸게 팔렸습니다.)
- 静かだ(しずかだ, 조용하다) → 静かに(しずかに, 조용히) — 静かに話してください。(조용히 말해주세요.)
- 上手だ(じょうずだ, 잘하다) → 上手に(じょうずに, 잘) — 上手に歌います。(잘 노래합니다.)

예외: いい(좋다)는 불규칙 형용사라서 부사형도 い→く 규칙 그대로가 아니라 よく(良く)로 바뀐다 — いく가 아니라 よく다.

## 형용사 → 동사: くなる/くする, になる/にする

부사형(く/に)에 なる(되다)나 する(하다)를 붙이면 "~해지다/~하게 만들다"라는 동사가 된다.

- なる(저절로 그렇게 됨) → 자동사 느낌
- する(그렇게 만듦) → 타동사 느낌

[일본어 자동사 타동사](notes/일본어/일본어_자동사_타동사.md)에서 배운 "저절로 vs 누가 시켜서"라는 감각이 여기서도 그대로 적용된다.

예:
- 高い(비싸다) → 高くなる(비싸지다) / 高くする(비싸게 만들다)
- 静かだ(조용하다) → 静かになる(조용해지다) / 静かにする(조용하게 하다)

- 値段が高くなりました。(가격이 비싸졌습니다.) — 저절로 그리 됨
- 部屋を静かにしてください。(방을 조용하게 해주세요.) — 누가 그렇게 만듦

[일본어 명령형·금지형](notes/일본어/일본어_명령형_금지형.md)에서 다뤘던 "静かにしろ!(조용히 해!)"도 사실 이 조합이다 — 静かに(부사형) + する의 명령형 しろ.

## 형용사 → 명사: さ vs み

い형용사 어간에 さ나 み를 붙이면 명사가 된다. 둘 다 "~함/~기"에 해당하지만 뉘앙스가 다르다.

- さ — 객관적으로 측정 가능한 정도. 대부분의 형용사에 폭넓게 씀.
- み — 주관적으로 느껴지는 감각. 일부 형용사(주로 감각·감정 계열)에만 제한적으로 씀.

예:
- 高い(높다) → 高さ(높이, 숫자로 잴 수 있음) — この山の高さは3000メートルです。(이 산의 높이는 3000미터입니다.)
- 大きい(크다) → 大きさ(크기) / 長い(길다) → 長さ(길이) — 둘 다 측정 가능
- 痛い(아프다) → 痛み(아픔, 몸이 느끼는 감각) — 心の痛みを感じます。(마음의 아픔을 느낍니다.)
- 悲しい(슬프다) → 悲しみ(슬픔) / 甘い(달다) → 甘み(단맛, 혀로 느끼는 단맛)

구분 팁: 자로 재거나 숫자로 나타낼 수 있으면 さ, 몸이나 마음으로 느끼는 감각이면 み다. 高み(높은 곳이라는 느낌)처럼 예외적으로 둘 다 존재하는 단어도 있지만, 뜻이 미묘하게 갈린다(高さ=수치상 높이, 高み=심리적으로 "높은 경지").

## 동사 → 명사: ます형 어간이 그대로 명사로

1류동사는 ます형 어간(연용형) 자체가 독립된 명사로 굳어지는 경우가 많다.

예:
- 遊ぶ(あそぶ, 놀다) → 遊び(あそび, 놀이)
- 帰る(かえる, 돌아가다) → 帰り(かえり, 귀가)
- 始まる(はじまる, 시작되다) → 始まり(はじまり, 시작)
- 休む(やすむ, 쉬다) → 休み(やすみ, 휴식/방학)
- 話す(はなす, 말하다) → 話(はなし, 이야기) — す가 탈락하고 어간 그대로

- 夏休みはいつからですか。(여름방학은 언제부터입니까?)
- 面白い話を聞きました。(재미있는 이야기를 들었습니다.)

중요한 구분: [일본어 명사화 표현](notes/일본어/일본어_명사화_표현.md)에서 배운 の/こと는 문장 전체를 명사처럼 취급하는 문법 장치였다("本を読むのが好き"). 반면 이건 동사 단어 하나 자체가 통째로 새 명사 단어가 되는 것이다 — 遊び는 사전에 실린 독립 단어이지, "遊ぶ+の"를 줄인 게 아니다. 문법 규칙이 아니라 단어 형성(조어)이라는 게 이 파트 전체의 핵심이다.
