# 중국어 발음 팁

`중국어_발음`에서 배운 음운 구조를 실전에서 어떻게 적용·구별·교정하는지의 실용 팁 모음.

## 촛불(손바닥) 테스트로 유기음·무기음 구별하기

`중국어_발음.md`에 유기음(有氣音) vs 무기음(無氣音)이 뭔지는 이미 배웠음. 여기선 실전에서 **직접 구별하는 방법**.

**방법**: 입 앞 5cm에 손바닥이나 얇은 종이 놓고 발음.

- **유기음** (p, t, k, c, q, ch) → 훅 하고 공기 뿜어져 나옴, 손바닥에 바람 느껴짐, 종이면 펄럭임
- **무기음** (b, d, g, z, j, zh) → 공기 거의 안 나옴, 손바닥 그대로

예:
```
怕 pà (유기, 훅!) vs 爸 bà (무기, 훅 없음)
```
둘 다 한국어 귀엔 "파/빠"처럼 들려서 헷갈리기 쉬움. 손 테스트가 귀보다 정확함.

**한국어 비유**: 한국어는 예사소리(ㅂㄷㄱ)·된소리(ㅃㄸㄲ)·거센소리(ㅍㅌㅋ) 3중 구분이지만, 중국어는 무기음(≈예사소리)·유기음(≈거센소리) 2중 구분뿐. "빠"처럼 된소리로 힘줘 발음하면 오히려 둘 다 아닌 제3의 소리가 되어버림 — 무기음은 힘 빼고 그냥 예사소리로.

## 반3성(半三聲) — 3성 뒤에 3성 아닌 게 오면 절반만 발음

`중국어_발음.md`에서 3성의 온전한 곡선(214, 내려갔다 올라옴)과 변성조 규칙(3성+3성 → 2성+3성)은 이미 배웠음. 근데 실전 회화에서 3성이 **가장 자주 나오는 형태**는 따로 있음.

**규칙**: 3성 뒤에 1성·2성·4성·경성이 오면 (즉 3성+3성이 *아니면*), 3성은 **내려가는 부분만** 발음하고 다시 올라오지 않아도 됨. 이걸 **반3성**이라 부름.

```
你好 nǐ hǎo → 3성+3성이므로 이건 예외 (변성조: ní hǎo로 바뀜, 이미 배운 규칙)
```
```
我们 wǒmen  (3성+경성) → wǒ는 내려가기만, 다시 안 올라옴
很忙 hěn máng (3성+2성) → hěn은 내려가기만
```

**왜 실전 요령인가**: 원어민 자연스러운 발화 속도에서 3성을 매번 끝까지 올려 발음하면 오히려 부자연스럽고 느리게 들림. "내려간 채로 다음 음절로 넘어가는" 게 표준 발음.

**한국어 비유**: 한국어 억양에서 문장 끝 살짝 낮췄다가 굳이 다시 안 올려도 되는 것과 비슷함 — 곡선의 절반만 실현해도 의미·자연스러움엔 문제없음. 다만 3성+3성 조합만은 반드시 변성조 규칙(2성+3성)을 먼저 적용하고 나서 이 반3성 원리를 봐야 함 — 순서 헷갈리지 말 것.

## 계이름으로 4성 익히기 — 음높이를 숫자가 아니라 노래로

`중국어_발음.md`에서 4성의 음높이 곡선(1성 55, 2성 35, 3성 214, 4성 51 — 5단계 음높이 표기)은 이미 배웠음. 근데 그 숫자를 실제 목소리 높낮이로 옮기기 막막할 때 쓰는 실전 요령.

**계이름 매핑** (5음계로 단순화):
```
1성 (55)  →  "솔" 을 쭉 평평하게 길게        (높고 평탄)
2성 (35)  →  "미" 에서 "솔" 로 확 올라가듯    (질문하듯 "뭐?")
3성 (214) →  "레" 에서 "도" 로 내려갔다 "파"로 살짝 (한숨 쉬듯 낮게 깔았다 살짝)
4성 (51)  →  "솔" 에서 "도" 로 뚝 떨어지듯    (명령하듯 "안 돼!")
```

예시 문장으로 실제 노래하듯 연습:
```
妈 mā (1성, 솔 쭉) — 麻 má (2성, 미→솔) — 马 mǎ (3성, 레→도→파) — 骂 mà (4성, 솔→도 뚝)
```

**왜 노래가 효과적인가**: 성조는 "음의 높낮이"가 아니라 "음의 궤적(멜로디)"임. 숫자표(214 같은)로 외우면 머리로는 알아도 입이 안 따라감. 노래하듯 흥얼거리면 몸이 궤적을 기억함.

**한국어 비유**: 한국어는 성조 언어가 아니라서 "마"를 어떻게 발음해도 뜻이 안 바뀌지만, 노래방에서 음정 맞추듯 "마"를 부른다고 생각하면 이해가 빠름 — 妈/麻/马/骂는 같은 가사를 4개의 다른 멜로디로 부르는 셈.

## 권설음, 영어 R처럼 혀를 말면 안 되는 이유

`중국어_발음.md`에서 권설음(zh ch sh r)은 "혀를 말아 입천장 뒤"에서 낸다고 배웠음. 근데 한국인 학습자 대부분이 여기서 **영어 R 발음 버릇**을 그대로 가져와 틀림.

**핵심 차이**: 영어 R은 혀끝이 입천장 **어디에도 안 닿고 공중에 뜬 채** 동그랗게 마는 소리. 중국어 권설음은 혀끝을 **입천장(경구개 뒤쪽)에 살짝 스치듯 닿게** 말아 올리는 소리 — 완전히 붙이지도, 완전히 띄우지도 않음.

**구별 요령**:
```
영어 R (red) → 혀끝 공중에 뜸, 입천장 안 닿음, 성대만 울려서 "우웨" 같은 소리
중국어 r (rén 人) → 혀끝이 입천장 뒤쪽에 살짝 스침, 마찰 소리 섞임
```
영어 R로 rén을 발음하면 원어민 귀엔 "웬" 비슷하게 들려서 아예 다른 음절로 오해받음.

**연습법**: z/c/s(치음)를 먼저 발음하다가, 혀끝을 그대로 뒤로 밀어 입천장에 살짝 닿을 때까지 이동시키면서 zh/ch/sh로 전환 — z→zh, c→ch, s→sh 순서로 혀 위치만 뒤로 옮기는 연습이 가장 정확함.

**한국어 비유**: 한국어 ㄹ은 혀끝이 윗잇몸을 톡 치고 떨어지는 탄음(彈音)이라 아예 다른 메커니즘. 오히려 "쥐/취/쉬"를 발음할 때 혀를 억지로 더 뒤로, 더 위로 말아 올린다고 생각하는 게 가까움.

## ü 발음 요령 — "이" 입모양 그대로, 입술만 오므리기

`중국어_발음.md`에서 ü는 "원순 전설 모음"이라 배웠음. 정의는 알아도 실제로 입에서 나오게 하는 게 어려운 대표적인 소리라 별도 요령 필요.

**방법**: 한국어 "이" 발음할 때 혀 위치는 **그대로 고정**한 채, 입술만 "우" 발음하듯 동그랗게 오므림.

```
1단계: "이" 발음 (혀는 앞쪽, 입술은 옆으로 벌림)
2단계: 혀는 그 자리 그대로 두고, 입술만 오므려서 동그랗게
       → 이 상태에서 나오는 소리가 ü
```

절대 하면 안 되는 것: "우" 소리부터 시작해서 입모양 바꾸기 — 그러면 혀가 뒤로 밀려서 완전히 다른 소리(중국어에 없는 소리, 또는 u)가 됨. **혀는 안 움직이고 입술만 움직이는 게 핵심.**

```
女 nǚ — "니" 발음하다가 입술만 오므리면 "뉘"에 가까운 소리로 자연스럽게 바뀜
绿 lǜ — "리" + 입술 오므림
```

**한국어 비유**: 한국어 "위"와 비슷하다고 생각하기 쉬운데, 표준 한국어 "위"는 사실 이중모음(우+이가 빠르게 연결)으로 발음되는 경우가 많아서 그대로 가져오면 ü가 아니라 살짝 다른 소리가 됨. "위"보다는 프랑스어 "u" (tu의 u)나 독일어 ü에 가까움 — 곧 "이 모양 입술로 우를 낸다"는 그 감각 자체가 핵심.
