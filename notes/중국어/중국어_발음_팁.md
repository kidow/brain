# 중국어 발음 팁

`중국어_발음`에서 배운 음운 구조를 실전에서 어떻게 적용·구별·교정하는지의 실용 팁 모음.

## 촛불(손바닥) 테스트로 유기음·무기음 구별하기

`중국어_발음.md`에 유기음(有氣音) vs 무기음(無氣音)이 뭔지는 이미 배웠음. 여기선 실전에서 **직접 구별하는 방법**.

**방법**: 입 앞 5cm에 손바닥이나 얇은 종이 놓고 발음.

- **유기음** (p, t, k, c, q, ch) → 훅 하고 공기 뿜어져 나옴, 손바닥에 바람 느껴짐, 종이면 펄럭임
- **무기음** (b, d, g, z, j, zh) → 공기 거의 안 나옴, 손바닥 그대로

예:
```
怕 pà (유기, 훅!) vs 爸 bà (무기, 훅 없음)
```
둘 다 한국어 귀엔 "파/빠"처럼 들려서 헷갈리기 쉬움. 손 테스트가 귀보다 정확함.

**한국어 비유**: 한국어는 예사소리(ㅂㄷㄱ)·된소리(ㅃㄸㄲ)·거센소리(ㅍㅌㅋ) 3중 구분이지만, 중국어는 무기음(≈예사소리)·유기음(≈거센소리) 2중 구분뿐. "빠"처럼 된소리로 힘줘 발음하면 오히려 둘 다 아닌 제3의 소리가 되어버림 — 무기음은 힘 빼고 그냥 예사소리로.

## 반3성(半三聲) — 3성 뒤에 3성 아닌 게 오면 절반만 발음

`중국어_발음.md`에서 3성의 온전한 곡선(214, 내려갔다 올라옴)과 변성조 규칙(3성+3성 → 2성+3성)은 이미 배웠음. 근데 실전 회화에서 3성이 **가장 자주 나오는 형태**는 따로 있음.

**규칙**: 3성 뒤에 1성·2성·4성·경성이 오면 (즉 3성+3성이 *아니면*), 3성은 **내려가는 부분만** 발음하고 다시 올라오지 않아도 됨. 이걸 **반3성**이라 부름.

```
你好 nǐ hǎo → 3성+3성이므로 이건 예외 (변성조: ní hǎo로 바뀜, 이미 배운 규칙)
```
```
我们 wǒmen  (3성+경성) → wǒ는 내려가기만, 다시 안 올라옴
很忙 hěn máng (3성+2성) → hěn은 내려가기만
```

**왜 실전 요령인가**: 원어민 자연스러운 발화 속도에서 3성을 매번 끝까지 올려 발음하면 오히려 부자연스럽고 느리게 들림. "내려간 채로 다음 음절로 넘어가는" 게 표준 발음.

**한국어 비유**: 한국어 억양에서 문장 끝 살짝 낮췄다가 굳이 다시 안 올려도 되는 것과 비슷함 — 곡선의 절반만 실현해도 의미·자연스러움엔 문제없음. 다만 3성+3성 조합만은 반드시 변성조 규칙(2성+3성)을 먼저 적용하고 나서 이 반3성 원리를 봐야 함 — 순서 헷갈리지 말 것.
