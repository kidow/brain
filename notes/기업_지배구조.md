# 기업 지배구조

## 순환출자(Circular Shareholding)

계열사끼리 **A → B → C → A** 처럼 고리 모양으로 지분을 갖는 구조.
(A↔B 처럼 두 회사가 서로 직접 갖는 건 **상호출자** — 대기업집단에선 아예 금지)

```
총수 ──(소수 지분)──▶ A
                     │ 출자
                     ▼
          C ◀──출자── B
          │
          └──출자──▶ A   ← 고리가 닫힘
```

### 왜 문제인가

**1. 가공자본 — 돈이 안 들어왔는데 자본이 늘어남**

외부 자금 100억으로 A 설립 → A가 B에 50억 출자 → B가 C에 30억 출자 → C가 A에 20억 증자.

- A 장부상 자본: 120억
- 실제 외부에서 들어온 돈: 100억
- 차이 20억 = 고리를 한 바퀴 돈 **같은 돈** (가공자본)

**2. 적은 지분으로 그룹 전체 지배**

총수는 고리 중 한 곳만 쥐면 나머지는 계열사 지분이 대신 지켜줌.
→ 총수 실제 지분(현금흐름권)과 행사하는 지배력(의결권)이 크게 벌어짐.

**3. 연쇄 부실**

고리 중 한 회사가 무너지면 출자한 회사 자산도 같이 깎임 → 도미노.

### 규제

- 2014년 개정 공정거래법: 대기업집단의 **신규** 순환출자 금지
- **기존** 고리는 금지 대신 공시 의무 → 자율 해소 유도

### 실제 사례 (소유지분도, 2026. 5. 1. 기준)

**현대자동차 — 고리가 아직 남아 있음**

```
정의선 ─ 현대차 2.1% · 기아 1.8% · 현대모비스 0.3%

현대차 ──35.2%──▶ 기아
  ▲                 │
17.3%             18.1%
  │                 ▼
  └──── 현대모비스 ◀─┘
```

정의선 직접 지분은 셋 다 2% 남짓인데, 고리 덕분에 세 회사가 서로를 지켜줌.

**삼성 — 2018년에 고리 해소**

- 2018년 4월: 삼성SDI가 삼성물산 지분 매각 → 고리 7개 중 3개 해소
- 2018년 9월: 삼성전기·삼성화재가 삼성물산 지분 매각 → 전부 해소

지금은 고리 없이 위에서 아래로만 흐름:

```
이재용 ──21.8%──▶ 삼성물산 ──19.3%──▶ 삼성생명 ──7.5%──▶ 삼성전자
                       └──────────── 4.5% ────────────▶ 삼성전자
```

**LG — 처음부터 나무 모양(지주회사 체제)**

구광모 ──16.0%──▶ ㈜LG ──▶ LG전자 · LG화학 · LG유플러스 …

화살표가 위에서 아래로만 가고 되돌아오는 선이 없음. 순환출자의 정반대 구조.

> 소유지분도 읽는 법: 화살표 = 출자 방향, 숫자 = 지분율(%), ★ = 상장사. **화살표를 따라가다 출발점으로 돌아오면 순환출자.**
