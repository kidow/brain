# 음악 믹싱 심화

## EQ 주파수 대역 심화

주파수 대역 구분:

| 대역 | 범위 | 담당 소리 |
|------|------|----------|
| Sub bass | 20~60Hz | 808의 가장 낮은 부분, 몸으로 느껴짐 |
| Bass | 60~250Hz | 킥, 베이스의 몸통 |
| Low-mid | 250~500Hz | 소리의 "두께", 과하면 진흙 같음 |
| Mid | 500Hz~2kHz | 보컬·신스의 core, 대부분 악기가 겹침 |
| High-mid | 2~4kHz | 명료함, 어택감 |
| High | 4~10kHz | 하이햇, 신스의 반짝임 |
| Air | 10kHz+ | 공기감, 화사함 |

실전 사용 — 컷(Cut) vs 부스트(Boost):
```
킥 EQ:  60Hz 부스트 (묵직함) + 400Hz 컷 (진흙 제거)
808 EQ: 40Hz 부스트 + 킥과 겹치는 대역 컷 (충돌 방지)
하이햇:  8kHz 부스트 (반짝임) + 200Hz 이하 컷 (불필요한 저음 제거)
```

핵심 원칙: 부스트보다 **컷이 우선**. 불필요한 대역을 먼저 깎으면 필요한 대역이 자연스럽게 도드라짐.

**Q:** EQ는 BPM이랑 어떻게 다른가?
**A:** 완전히 다른 축. BPM = 시간 축(1분에 박자 몇 번, 언제 소리 나는지). EQ = 주파수 축(소리가 얼마나 낮은음/높은음인지, 음색). 서로 독립적 — BPM 바꿔도 EQ 안 바뀌고, EQ 바꿔도 BPM 안 바뀜.

## 컴프레서(Compressor)

소리의 음량 편차를 줄이는 도구. 큰 소리는 낮추고, 작은 소리는 상대적으로 도드라지게.

4개 핵심 파라미터:
| 파라미터 | 역할 |
|---------|------|
| Threshold | 이 음량을 넘으면 압축 시작 |
| Ratio | 얼마나 세게 누르나 (4:1 = 넘은 만큼의 1/4만 통과) |
| Attack | 압축 시작까지 걸리는 시간 |
| Release | 압축이 풀리기까지 걸리는 시간 |

비유: 호스 입구를 손가락으로 살짝 눌러 너무 세게 나오는 물살만 일정하게 만드는 것.

킥 드럼 컴프레션 예시:
```
Threshold: -12dB
Ratio: 4:1
Attack: 10ms    — 타격 초반은 그대로 두고
Release: 100ms  — 빠르게 원상복구
```

Attack을 느리게 설정하면 킥의 초반 타격감(펀치)을 살리면서 뒷부분만 눌러줌. Phonk 킥의 딱딱한 느낌이 여기서 나옴.

핵심: 컴프레서는 소리를 작게 만드는 게 아니라 **편차를 줄여서 전체적으로 더 크고 일정하게** 들리게 함.

## 사이드체인 컴프레션(Sidechain Compression)

기본 컴프레서는 자기 소리로 자기를 누름. 사이드체인은 **다른 트랙의 소리로 이 트랙을 누름**.

가장 흔한 사용법 — 킥이 베이스를 누르기:
```
설정: 808 베이스 트랙 컴프레서 → 사이드체인 입력 = 킥 드럼
결과: 킥이 "쿵" 칠 때마다 808 순간적으로 작아짐 → 지나가면 원래대로
```

이유: 킥과 808은 같은 저음 대역 사용. 동시에 최대 음량이면 서로 뭉개짐. 사이드체인으로 킥 칠 때마다 808을 살짝 비켜주면 둘 다 선명하게 들림.

펌핑(Pumping) 효과: 사이드체인을 과하게 걸면 배경음이 박자에 맞춰 "숨쉬듯" 규칙적으로 작아졌다 커짐. EDM에서 의도적으로 강조하기도 함.

Suno 프롬프팅:
```
sidechain pumping bass        # 펌핑 효과 있는 베이스
tight kick and bass interplay # 킥·베이스 사이드체인 느낌
```

Suno는 자동 믹싱이라 이미 내장. FL Studio 직접 작업 시 수동으로 걸어야 함.

## 리버브(Reverb)

공간감을 만드는 이펙트. 소리가 실제 공간(방·홀·동굴)에서 반사되어 울리는 것을 시뮬레이션.

핵심 파라미터:
| 파라미터 | 역할 |
|---------|------|
| Room size | 공간의 크기 |
| Decay | 울림이 사라지는 시간 |
| Wet/Dry | 원음 대비 리버브 소리 비율 |
| Pre-delay | 원음과 리버브 시작 사이 시간차 |

```
Dry (리버브 없음) = 소리가 바로 앞에서 남
Wet (리버브 많음) = 소리가 멀리서, 큰 공간에서 나는 느낌
```

Phonk 활용:
- 보컬/샘플: 살짝 걸어 "예전 녹음" 같은 아련함 (테이프 감성)
- 신스 멜로디: 몽환적·귀신 들린 느낌 강화
- 808/킥: 거의 안 씀 — 저음은 리버브 걸면 뭉개짐

주의: 리버브 과하면 믹스가 흐릿하고 먼 느낌. 저음(킥·808)은 드라이 유지, 고음(멜로디·보컬)에만 걸어야 선명함 유지.

Suno 프롬프팅:
```
reverb-drenched vocals      # 리버브 많이 걸린 보컬
dry, tight mix              # 리버브 없는 건조한 믹스
haunting reverb tail        # 길게 울리는 잔향
```

## 딜레이(Delay)

메아리 효과. 원음이 일정 시간 뒤에 반복. 리버브와 원리가 다름.

리버브 vs 딜레이:
| | 리버브 | 딜레이 |
|--|--------|--------|
| 원리 | 무수한 반사음이 섞여 뭉개짐 | 소리가 또렷하게 반복 |
| 느낌 | 공간감 | 리듬감 |
| 예시 | 동굴 속 웅웅거림 | "안녕-안녕-안녕" 메아리 |

핵심 파라미터:
| 파라미터 | 역할 |
|---------|------|
| Time | 반복 간격 (ms 또는 박자 단위) |
| Feedback | 몇 번 반복되나 (0%=1번, 50%=여러 번 점점 작게) |
| Wet/Dry | 원음 대비 딜레이 소리 비율 |

박자 맞춘 딜레이(Tempo Sync): Time을 ms 대신 음표 단위로 설정하면 BPM에 자동으로 맞춰짐.
```
1/4 delay = 4분음표 간격
1/8 delay = 8분음표 간격 (더 촘촘)
```
150 BPM에서 `1/8 delay` = 반복 간격 정확히 0.2초 (1마디 1.6초의 1/8).

Phonk 활용:
```
vocal chop with 1/8 delay        # 보컬 조각에 리듬감 있는 메아리
synth melody, tempo-synced delay # 멜로디에 박자 맞춘 딜레이
```

리버브 = 공간을 넓히는 도구, 딜레이 = 리듬을 풍성하게 만드는 도구.

## 새추레이션과 디스토션(Saturation & Distortion)

소리에 배음(harmonics)을 더해 따뜻하거나 거친 질감을 만드는 이펙트.

강도 스펙트럼:
```
Saturation (약함) ──────────────────→ Distortion (강함)
따뜻함, 아날로그 느낌              공격적, 찢어지는 소리
```

**새추레이션:** 아주 살짝 소리를 눌러 따뜻하고 두꺼운 느낌 추가. 아날로그 테이프·진공관 시뮬레이션. Phonk 테이프 질감의 원천.

**디스토션:** 소리를 강하게 찌그러뜨려 거칠고 공격적인 질감. 808에 걸면 공격적 저음, 신스 멜로디에 걸면 찢어지는 날카로움.

Phonk 실전 사용:
```
808 bass + light saturation      # 808에 살짝 (두께감)
808 bass + heavy distortion      # 808에 강하게 (공격성)
tape saturation on melody        # 멜로디에 빈티지 테이프 질감
```

이유: 디지털로 생성된 소리(신스·808)는 너무 "깨끗해서" 밋밋함. 배음을 더해 더 크고 존재감 있게 만듦. Suno의 `lo-fi tape saturation` 프롬프트가 이 개념.
