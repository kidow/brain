## 보안의 지도: CIA · 취약점 · 위협 · OWASP Top 10

**상황**
- "보안 신경 써 줘"라고 AI에게 말했는데, 무엇을 지켜야 하는지 **기준이 없으니** 결과도 확인할 수가 없다.
- 보안 기사를 읽으면 취약점·위협·공격·익스플로잇 같은 말이 섞여 나와 **같은 말인지 다른 말인지** 헷갈린다.
- 웹 보안 점검을 하려는데 **어디서부터 봐야 할지** 목록이 없다.

**용어**
- **CIA 3요소** — 보안이 지키려는 세 가지. 보안 사고는 이 중 **무엇이 깨졌나**로 설명할 수 있다.
  - **Confidentiality(기밀성)** — 볼 권한이 있는 사람**만** 볼 수 있어야 한다. 깨지면: 개인정보 유출, 남의 주문 내역 열람.
  - **Integrity(무결성)** — 허락받은 사람만, 허락된 방식으로**만** 바뀌어야 한다. 깨지면: 남의 글 수정, 결제 금액 조작.
  - **Availability(가용성)** — 필요할 때 **쓸 수 있어야** 한다. 깨지면: DDoS(Distributed Denial of Service)로 서비스 마비(인프라 용어 14번), 랜섬웨어로 데이터 잠김.
  - 비유: 은행 금고. 아무나 못 들여다보고(기밀성), 몰래 금액을 못 바꾸고(무결성), 고객이 찾을 때 열 수 있어야(가용성) 한다.
- **자주 섞이는 네 단어**
  - **vulnerability(취약점)** — 시스템의 **약한 곳**. "주문 API가 주인 확인을 안 한다."
  - **threat(위협)** — 그 약점을 **노릴 수 있는 존재·상황**. "다른 사용자, 자동화된 봇."
  - **attack / exploit(공격 / 익스플로잇)** — 약점을 **실제로 이용하는 행위·방법(코드)**. "주소의 id를 1씩 바꿔 가며 다 긁어 가기."
  - **risk(위험)** — **피해가 날 가능성 × 피해 크기**. 우선순위는 위험으로 정한다(기획 용어 8번 severity와 비슷한 발상).
  - 비유: 집 **창문 잠금장치 고장**(취약점), **동네 빈집털이범**(위협), 그 창문으로 **실제 침입**(공격), "1층이라 털리기 쉽고 귀중품이 많다"(위험).
- **attack surface(공격 표면)** — 바깥에서 건드릴 수 있는 **모든 지점**(인프라 용어 11번). 입력 칸, API 주소, 파일 업로드, 열린 포트, 설치한 라이브러리까지.
- **OWASP Top 10** — 보안 비영리 단체 **OWASP(Open Worldwide Application Security Project)**가 데이터로 정리한 **웹 애플리케이션의 가장 흔하고 위험한 취약점 10가지 분류**. 몇 년마다 새 판이 나오며 순서·구성이 조금씩 바뀌므로 점검할 땐 **최신판**을 확인한다. 꾸준히 상위에 오르는 범주:
  - **broken access control(접근 제어 실패)** — 남의 데이터·관리자 기능에 접근됨(다음 레슨, IDOR 포함)
  - **injection(주입)** — 입력이 명령으로 해석됨(웹 용어 25번 SQL injection, XSS 포함)
  - **cryptographic failures(암호화 실패)** — 민감 정보를 평문으로 저장·전송(인프라 용어 3번 HTTPS)
  - **authentication failures(인증 실패)** — 약한 비밀번호 저장, brute force 무방비(웹 용어 23번, 인프라 용어 14번)
  - **security misconfiguration(보안 설정 오류)** — 기본 설정 그대로, 디버그 모드, 열린 버킷
  - **vulnerable components / supply chain(취약한 구성 요소·공급망)** — 오래되거나 오염된 라이브러리(진단 Q3)
  - **insecure design(안전하지 않은 설계)**, **logging & monitoring failures(기록·감시 실패)**, **SSRF(Server-Side Request Forgery)** 등
  - 이 목록은 AI에게 보안 점검을 시킬 때 **체크리스트**로 쓰기 좋다(상황 1·3 해결).
