# 화학

## 순물질과 혼합물

화학에서는 물질을 먼저 순물질과 혼합물로 나눈다.
순물질은 성분의 종류와 비율이 일정한 물질이고, 혼합물은 두 가지 이상 물질이 물리적으로 섞인 것이다.
예: 증류수는 순물질에 가깝고, 소금물과 공기는 혼합물이다.

## 원소와 화합물

순물질은 다시 두 종류로 갈린다. 기준: 화학적 방법으로 더 쪼개지는가.

- 원소(홑원소 물질): 더 이상 다른 물질로 못 쪼갬. 한 종류 원자로만 구성. 예: O₂, Fe, Au, H₂
- 화합물: 두 종류 이상 원자가 정해진 비율로 결합. 화학적 방법(전기분해 등)으로 원소로 쪼개짐. 예: H₂O, NaCl, CO₂

예: 물 전기분해 → 수소 H₂ + 산소 O₂ (부피비 2:1). 여기서 더 안 쪼개짐 → 원소.

화합물 vs 혼합물 구분:

| | 혼합물 (소금물) | 화합물 (소금 NaCl) |
|---|---|---|
| 결합 | 물리적으로 섞임 | 화학적으로 결합 |
| 비율 | 마음대로 | 항상 고정 (Na:Cl = 1:1) |
| 분리 | 물리적 방법 | 화학적 방법만 |
| 성질 | 원래 성질 유지 | 완전히 새 성질 |

핵심: 화합물은 재료의 성질을 안 물려받는다. Na(폭발성 금속) + Cl₂(독가스) → NaCl(식용 소금).

계층: 물질 → 순물질(원소, 화합물) / 혼합물
