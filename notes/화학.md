# 화학

## 순물질과 혼합물

화학에서는 물질을 먼저 순물질과 혼합물로 나눈다.
순물질은 성분의 종류와 비율이 일정한 물질이고, 혼합물은 두 가지 이상 물질이 물리적으로 섞인 것이다.
예: 증류수는 순물질에 가깝고, 소금물과 공기는 혼합물이다.

## 원소와 화합물

순물질은 다시 두 종류로 갈린다. 기준: 화학적 방법으로 더 쪼개지는가.

- 원소(홑원소 물질): 더 이상 다른 물질로 못 쪼갬. 한 종류 원자로만 구성. 예: O₂, Fe, Au, H₂
- 화합물: 두 종류 이상 원자가 정해진 비율로 결합. 화학적 방법(전기분해 등)으로 원소로 쪼개짐. 예: H₂O, NaCl, CO₂

예: 물 전기분해 → 수소 H₂ + 산소 O₂ (부피비 2:1). 여기서 더 안 쪼개짐 → 원소.

화합물 vs 혼합물 구분:

| | 혼합물 (소금물) | 화합물 (소금 NaCl) |
|---|---|---|
| 결합 | 물리적으로 섞임 | 화학적으로 결합 |
| 비율 | 마음대로 | 항상 고정 (Na:Cl = 1:1) |
| 분리 | 물리적 방법 | 화학적 방법만 |
| 성질 | 원래 성질 유지 | 완전히 새 성질 |

핵심: 화합물은 재료의 성질을 안 물려받는다. Na(폭발성 금속) + Cl₂(독가스) → NaCl(식용 소금).

계층: 물질 → 순물질(원소, 화합물) / 혼합물

## 원자 구조

원소도 더 작은 단위로 쪼갤 수 있다. 화학적 방법으론 안 됨 — 물리학(핵) 영역.

원자 구성 입자 3종:

| 입자 | 위치 | 전하 | 질량(대략) |
|---|---|---|---|
| 양성자 | 원자핵 | + | 1 |
| 중성자 | 원자핵 | 없음 | 1 |
| 전자 | 핵 바깥, 궤도 | − | 1/1836 |

가운데 작고 무거운 핵(양성자+중성자), 주위를 가벼운 전자가 돈다. 원자 크기 대부분은 빈 공간.

원소를 결정하는 건 양성자 수 하나뿐 — 원자번호(Z). 양성자 1개=수소, 6개=탄소, 8개=산소. 중성자 수는 같은 원소라도 다를 수 있음(동위원소). 전자 수는 보통 양성자 수와 같아 전체 전하 0(중성 원자).

계층: 원자 → 원자핵(양성자, 중성자) / 전자

## 주기율표

원소 118개를 원자번호(양성자 수) 순서로 배열. 성질 비슷한 원소끼리 같은 세로줄에 오게 짜여 있다.

가로줄 = 주기(period): 왼쪽→오른쪽, 원자번호 1씩 증가. 주기 끝나면 다음 줄로 — 전자가 새 껍질 채우기 시작.

세로줄 = 족(group): 같은 족은 최외각 전자 수(가전자)가 같아 화학적 성질 비슷. 배열 기준은 원자번호지만 결과로 나온 세로 정렬이 성질을 묶어줌.

대표 족:
- 1족(수소 제외) 알칼리금속: Li, Na, K — 전자 1개 내주고 반응 잘함, 물에 격렬 반응
- 17족 할로겐: F, Cl, Br — 전자 1개 받으려 함, 반응성 강한 비금속
- 18족 비활성기체: He, Ne, Ar — 최외각 꽉 참, 거의 반응 안 함

## 전자 배치

전자는 정해진 껍질(에너지 준위)에 순서대로 채워진다. 1번째 껍질부터 꽉 채우고 다음 껍질로.

껍질별 최대 수용 전자 수: 1번째 2개, 2번째 8개, 3번째 8개(원소 20번까지는).

예시:
- 수소(Z=1): 1
- 탄소(Z=6): 2, 4
- 네온(Z=10): 2, 8 (완전히 참)
- 나트륨(Z=11): 2, 8, 1

주기율표와 연결: 주기(가로줄) = 몇 번째 껍질까지 쓰는지(나트륨은 3주기). 족(세로줄) = 최외각 전자 수(나트륨·리튬 둘 다 최외각 1개 → 1족).

최외각 전자가 화학반응을 담당(안쪽 껍질은 핵에 가려 반응에 안 낌). 나트륨이 전자 1개를 쉽게 내주는 이유 — 내주면 그 아래 꽉 찬 껍질이 최외각이 되어 안정(옥텟 규칙 예고).

## 이온 결합

원자는 최외각 전자를 8개(또는 2개)로 채워 안정해지려 한다 — 옥텟 규칙. 전자를 통째로 주거나 뺏어서 채우는 방식이 이온 결합.

Na(2,8,1) + Cl(2,8,7) 반응: Na가 전자 1개를 Cl에 준다.
- Na는 전자 1개 잃음 → Na⁺ (양이온)
- Cl은 전자 1개 얻음 → Cl⁻ (음이온)

이온 = 전자를 잃거나 얻어 전하를 띠게 된 원자. 잃으면 양이온(+), 얻으면 음이온(−).

Na⁺과 Cl⁻은 전하가 반대라 정전기적 인력으로 끌어당김 — 이온 결합. NaCl(소금) 생성.

이온 결합은 분자를 안 만든다. 물 분자처럼 콕 집을 하나의 단위가 없고, Na⁺과 Cl⁻이 3차원으로 규칙적으로 쌓여 거대한 결정을 이룬다 — 소금 결정이 딱딱하고 녹는점 높은 이유(결합력이 전체 결정 구조를 붙잡음).

일반 패턴: 금속(전자 내주기 쉬움, 왼쪽 족) + 비금속(전자 받기 쉬움, 오른쪽 족) → 이온 결합. 1족+17족이 대표 조합(1개 주고 1개 받으면 둘 다 옥텟 완성).

## 공유 결합

비금속끼리 만나면 둘 다 전자를 받고 싶어해 뺏을 수 없다. 대신 전자쌍을 공유해 둘 다 옥텟을 채운다.

H₂ 예: H 원자는 최외각(1번째 껍질)에 전자 1개, 정원 2개라 1개 모자람. H 두 개가 전자 1개씩 내놓고 공유 → 둘 다 공유 전자쌍을 자기 것처럼 계산해 2개 채운 걸로 침.

이렇게 묶인 원자 덩어리가 분자. 이온 결합과 달리 분자 하나를 콕 집어낼 수 있다(H₂ 하나, H₂O 하나).

H₂O: O(2,6)는 최외각 6개, 2개 모자람. H 두 개가 각각 O와 전자쌍 하나씩 공유해 O도 H도 옥텟(H는 2개) 완성.

이온 결합 vs 공유 결합:

| | 이온 결합 | 공유 결합 |
|---|---|---|
| 조합 | 금속 + 비금속 | 비금속 + 비금속 |
| 전자 | 완전히 이동 | 공유 |
| 단위 | 분자 없음, 거대 결정 | 분자 있음 |
| 예 | NaCl | H₂O, CO₂, O₂ |

전자쌍 여러 개 공유도 가능: O₂는 2쌍(이중 결합), N₂는 3쌍(삼중 결합) — N₂가 매우 안정해 공기 78% 차지해도 반응 잘 안 하는 이유.

## 화학반응식

반응물 → 생성물 형태로 쓴다. 화살표 왼쪽 반응 전, 오른쪽 반응 후.

틀린 예: `H₂ + O₂ → H₂O` — 왼쪽 O 2개, 오른쪽 O 1개, 원자가 사라짐. 화학반응은 원자를 새로 만들거나 없애지 못한다(질량 보존 법칙). 반응 전후 원자 개수가 양쪽에서 같아야 함.

균형 맞추기: 분자식 자체(아래첨자)는 못 바꾼다(H₂O를 H₂O₂로 바꾸면 다른 물질). 바꿀 수 있는 건 분자 앞 계수(정수 배수)뿐.

`2H₂ + O₂ → 2H₂O` — 왼쪽 H 4, O 2 / 오른쪽 H 4, O 2. 균형 맞음.

세는 요령: 계수 × 아래첨자 = 그 원소 총 원자 수(2H₂O → H 2×2=4, O 2×1=2).

메탄 연소 예: `CH₄ + 2O₂ → CO₂ + 2H₂O` — 왼쪽 C1 H4 O4 / 오른쪽 C1 H4 O4(2+2). 맞음.

요령: 가장 복잡한 분자(원자 종류 많은 것) 계수 1로 고정 후 나머지 조정. 탄소→수소→산소 순으로 맞추면 편함(산소는 여러 데 걸쳐 있어 마지막에).

## 반응 종류 분류

1. 화합 반응(Synthesis) A + B → AB — 둘 이상이 합쳐 하나로. `2H₂ + O₂ → 2H₂O`
2. 분해 반응(Decomposition) AB → A + B — 화합의 역방향, 열·전기·빛 필요. `2H₂O → 2H₂ + O₂`(전기분해)
3. 치환 반응(Single displacement) A + BC → AC + B — 한 원소가 화합물 속 다른 원소를 밀어내고 대신 들어감. `Zn + 2HCl → ZnCl₂ + H₂`
4. 복분해 반응(Double displacement) AB + CD → AD + CB — 두 화합물이 서로 짝 교환. 이온성 물질끼리 흔함. `AgNO₃ + NaCl → AgCl + NaNO₃`
5. 연소 반응(Combustion) — 탄화수소 + O₂ → CO₂ + H₂O, 항상 산소 필요·열/빛 방출. `CH₄ + 2O₂ → CO₂ + 2H₂O`

구분 요령: 왼쪽 여러→오른쪽 1개=화합, 왼쪽 1개→오른쪽 여러=분해, 원소가 화합물에 파고듦=치환, 화합물끼리 성분 교환=복분해, O₂ 붙고 CO₂+H₂O 나옴=연소.

## 산과 염기

물에 녹였을 때 내놓는 이온으로 구분.

산(Acid): 물에 녹아 수소 이온(H⁺)을 내놓는 물질. `HCl → H⁺ + Cl⁻`, `H₂SO₄ → 2H⁺ + SO₄²⁻`
염기(Base): 물에 녹아 수산화 이온(OH⁻)을 내놓는 물질. `NaOH → Na⁺ + OH⁻`, `KOH → K⁺ + OH⁻`

pH 척도(0~14)로 산성/염기성 표현. pH 7=중성. pH<7 산성(작을수록 강산, 위산 1~2). pH>7 염기성(클수록 강염기, 표백제 12~13).

pH는 로그 척도 — pH 1 차이 = H⁺ 농도 10배 차이. pH 3은 pH 5보다 H⁺ 100배 많음.

중화 반응: 산 + 염기 → 물 + 염. H⁺과 OH⁻이 만나 H₂O, 남은 이온끼리 짝지어 염.
`HCl + NaOH → NaCl + H₂O` — H⁺ + OH⁻ → H₂O가 핵심, NaCl은 부산물.

## 몰(mole)

원자·분자 개수가 너무 많아 묶음 단위로 센다.

1몰 = 6.02×10²³개(아보가드로 수, Nₐ). 이 숫자는 1몰의 질량(그램 수)이 원자량과 정확히 일치하게 정해짐.

원자량 연결: 탄소 원자량 12 → 탄소 12g = 1몰. 산소 16 → 16g = 1몰. 수소 1 → 1g = 1몰.

분자량(원자량 합)도 동일: H₂O 분자량 = 1×2+16 = 18 → 물 18g = 1몰 = 분자 6.02×10²³개.

반응식 계수는 몰 비율이기도 함: `2H₂ + O₂ → 2H₂O`는 "수소 2몰 + 산소 1몰 → 물 2몰". 그램 수 측정 → 몰 환산 → 반응식 비율 적용 → 그램 재환산, 이 흐름이 화학량론(stoichiometry)의 핵심.

## 산화-환원 반응 (Redox)

이온 결합의 전자 이동을 일반화한 개념. 완전 이동이 아니라 전자가 한쪽으로 쏠리기만 해도 산화-환원.

산화(Oxidation) = 전자를 잃음. 환원(Reduction) = 전자를 얻음. 암기: LEO(Lose Electron=Oxidation)가 GER(Gain Electron=Reduction)에게 말한다.

산화와 환원은 항상 짝으로 일어남 — 누가 잃으면 반드시 누가 받음.

`2Na + Cl₂ → 2NaCl`: Na는 전자 잃음(0→+1)=산화, Cl은 전자 얻음(0→−1)=환원. 이온 결합은 산화-환원의 극단적(전자 완전 이동) 케이스.

공유 결합에서도 발생: `CH₄ + 2O₂ → CO₂ + 2H₂O`에서 탄소는 산소 쪽에 전자 뺏기는 쪽(산화), 산소는 끌어당기는 쪽(환원) — 전자가 완전히 안 넘어가도 더 많이 끌어당기는 쪽으로 쏠리면 산화-환원으로 침(전기음성도로 판단).

산화제(oxidizing agent) = 남을 산화시킴, 자기는 환원됨 — 예: Cl₂, O₂
환원제(reducing agent) = 남을 환원시킴, 자기는 산화됨 — 예: Na, CH₄
(이름은 상대방에게 시키는 역할 기준 — 헷갈리기 쉬움)

연소·부식(녹슬기)·배터리 전부 산화-환원 반응. 철이 녹스는 것도 Fe가 O₂에 전자를 뺏기는 산화.

## 전기음성도

공유 결합에서 전자쌍이 어느 쪽으로 쏠리는지 숫자로 판단하는 척도. 폴링 척도 0.7(세슘)~4.0(불소).

주기율표 규칙: 오른쪽 위로 갈수록 증가(18족 비활성기체 제외). 가로: 왼쪽→오른쪽 증가. 세로: 아래→위 증가(껍질 적을수록 핵이 전자를 더 세게 끌어당김).

최강 불소(4.0), 다음 산소(3.5), 질소·염소(3.0).

전기음성도 차이로 결합 성격 구분:

| 차이 | 결합 성격 | 예 |
|---|---|---|
| 0 | 무극성 공유 결합 | H₂, O₂, Cl₂ |
| 0 초과~1.7 미만 | 극성 공유 결합 | H₂O, HCl |
| 1.7 이상 | 이온 결합 | NaCl(차이 2.1) |

이온 결합과 공유 결합은 딱 나뉜 두 종류가 아니라 전기음성도 차이라는 하나의 축 위의 스펙트럼.

물(H₂O) 예: O(3.5)가 H(2.1)보다 전기음성도 높아 공유 전자쌍을 더 세게 당김 → O 쪽 δ−(부분 음전하), H 쪽 δ+(부분 양전하). 이 부분 전하가 물이 극성 분자인 이유 — 용해력·표면장력·얼음이 물에 뜨는 성질의 출발점.

## 분자 간 힘 — 수소 결합과 물의 특이성

이온·공유 결합은 분자를 만드는 힘. 분자 간 힘은 분자와 분자 사이를 붙잡는 힘(훨씬 약함) — 끓는점·어는점·상태를 결정.

세기 순서:
1. 분산력(London dispersion force) — 모든 분자에 존재, 가장 약함. 순간 유도 쌍극자. 분자 클수록(전자 많을수록) 강해짐.
2. 쌍극자-쌍극자 힘 — 극성 분자끼리(δ+, δ− 있음) 반대 극 인력.
3. 수소 결합 — 쌍극자-쌍극자의 강한 버전. 조건: H가 N, O, F에 직접 결합. 이 셋 전기음성도 매우 높아 δ+/δ− 편차 크고, H가 작아 이웃 분자에 가깝게 접근 가능.

물(H₂O): O-H 두 개, 조건 충족. δ− O가 옆 물 분자의 δ+ H를 끌어당겨 사슬처럼 얽힘.

수소 결합이 만드는 물의 특이 성질:
- 끓는점 비정상적으로 높음: 분자량 비슷한 H₂S(34)는 실온 기체인데 물(18)은 액체.
- 얼음이 물에 뜸: 얼면 수소 결합이 육각 격자 이루며 부피 늘어남(빈 공간 많음) → 밀도가 액체보다 낮음. 대부분 물질은 반대(고체 밀도 > 액체).
- 표면장력 큼: 표면 분자가 옆·아래로만 수소 결합 당겨 안쪽으로 뭉치려는 힘(소금쟁이가 물 위를 걷는 이유).

## 상태 변화

물질 상태(고체/액체/기체)는 분자 간 힘 vs 열운동의 줄다리기로 결정.

- 고체: 분자 간 힘이 이김. 입자 고정, 진동만. 모양·부피 일정.
- 액체: 힘과 열운동 비등비등. 입자 이동 가능. 부피 일정, 모양은 그릇 따라감.
- 기체: 열운동이 이김. 분자 간 힘 무시 수준. 모양·부피 둘 다 그릇 따라감.

온도 = 입자 평균 운동 에너지. 온도 오르면 열운동이 세져 분자 간 힘을 이기기 시작 → 고체→액체→기체.

상태 변화 이름: 고체→액체 융해, 액체→고체 응고, 액체→기체 기화, 기체→액체 액화, 고체→기체/기체→고체 승화(양방향 다 승화).

분자 간 힘 강할수록 끓는점 높음: 수소 결합 있는 물(100°C) vs 없는 비슷한 크기 메탄 CH₄(−162°C). 물이 예외적으로 넓은 액체 범위(0~100°C)를 갖는 이유.

상태 변화 중엔 온도가 안 오름(잠열, latent heat) — 얼음이 녹는 동안(0°C 유지) 넣는 열은 온도를 올리는 게 아니라 분자 간 힘을 끊는 데 쓰임. 다 끊고 나서야 온도 다시 오름.

## 반응 속도

반응식은 무엇이 무엇 되는지만 말함, 얼마나 빨리는 안 알려줌. 이걸 다루는 게 반응 속도론.

충돌 이론 — 반응 일어나려면 두 조건 다 필요: 1) 적절한 방향으로 충돌, 2) 충분한 에너지(활성화 에너지 Ea 이상)로 충돌.

활성화 에너지(Ea): 반응물이 생성물 되기 전 넘어야 하는 에너지 언덕.

속도 영향 요인:
- 온도↑ → 속도↑ (분자 운동 빨라져 충돌 빈도·에너지 둘 다↑)
- 농도(기체는 압력)↑ → 속도↑ (단위 부피당 분자 수↑, 충돌 빈도↑)
- 표면적↑ → 속도↑ (고체 쪼갤수록 접촉면↑, 가루가 각설탕보다 빨리 반응)
- 촉매 첨가 → 속도↑ (다른 경로로 Ea 자체를 낮춤)

촉매: 반응물도 생성물도 아님, 반응 끝나면 그대로 남아 소모 안 됨. Ea 언덕을 낮은 우회로로 바꿔줌.

## 화학 평형

가역 반응(reversible reaction): 정반응·역반응 둘 다 일어남. `N₂ + 3H₂ ⇌ 2NH₃`

평형 = 반응이 멈춘 게 아니라 정반응 속도 = 역반응 속도가 된 상태. 미시적으론 계속 반응 중, 만들어지는 양=없어지는 양이라 겉보기 농도 고정.

르 샤틀리에 원리: 평형에 외부 변화(농도·온도·압력)를 주면 그 변화를 상쇄하는 방향으로 평형 이동.

`N₂ + 3H₂ ⇌ 2NH₃ + 열` 예:
- N₂ 추가 → 정반응 쪽(NH₃ 더 생김)
- NH₃ 제거 → 정반응 쪽
- 온도 올림 → 역반응 쪽(정반응이 발열이라 열 없애는 흡열 방향으로)
- 압력 올림(기체 반응) → 분자 수 적은 쪽(왼쪽 4몰→오른쪽 2몰이라 정반응 쪽)

실용: 하버법(암모니아 대량 생산)이 이 원리 이용 — 고압+저온으로 정반응 밀어 NH₃ 수율 올림(비료 생산 핵심 공정).

## 유기화학 입문

탄소 화합물만 다루는 분야. 탄소가 만드는 화합물 종류가 나머지 원소 전부 합친 것보다 많음(수백만 종).

탄소(C, Z=6) 전자 배치 2,4 — 최외각 4개, 공유 결합 4개 가능(결합 손이 많음).

카테네이션(catenation): 탄소는 탄소끼리 사슬·고리를 길게 만들 수 있음. `CH₃-CH₂-CH₂-CH₃`(부탄). 다른 원소는 이 정도로 자기들끼리 못 이어짐 — 탄소 화합물 다양성의 근원.

탄화수소(탄소+수소만):

| 종류 | 결합 | 예 | 특징 |
|---|---|---|---|
| 알케인(alkane) | 단일(C-C) | 메탄 CH₄, 에탄 C₂H₆ | -ane |
| 알켄(alkene) | 이중(C=C) | 에틸렌 C₂H₄ | -ene |
| 알카인(alkyne) | 삼중(C≡C) | 아세틸렌 C₂H₂ | -yne |

탄소 개수 접두어: meth-(1) eth-(2) prop-(3) but-(4) pent-(5) hex-(6). 메탄=탄소1, 에탄=탄소2, 프로판=탄소3.

작용기(functional group) — 탄화수소 뼈대에 붙어 성질을 결정:
- -OH(하이드록시기) → 알코올. 예: 에탄올 C₂H₅OH
- -COOH(카복시기) → 카복실산(산성). 예: 아세트산(식초) CH₃COOH
- -NH₂(아미노기) → 아민. 아미노산(단백질)의 핵심 부분.

## 이성질체

같은 분자식이지만 연결 방식이 달라 완전히 다른 물질이 되는 화합물 — 이성질체(isomer).

부탄 C₄H₁₀ 예: 노말부탄(곧은 사슬 CH₃-CH₂-CH₂-CH₃)과 이소부탄(가지 달림) — 분자식 동일, 끓는점 다름(각각 −0.5°C, −11.7°C).

탄소 개수 늘수록 이성질체 수 폭발적 증가: C₄H₁₀는 2개, C₁₀H₂₂는 75개, C₃₀H₆₂는 40억 개 이상. 탄소 개수만으로 화합물이 안 정해짐 — 연결 구조가 진짜 정체성.

분자식(원자 개수만, C₄H₁₀) vs 구조식(연결 방식까지, CH₃-CH₂-CH₂-CH₃) — 분자식만 보고 물질 하나로 특정 불가.

## 몰 농도

용액의 진하기를 숫자로: 몰 농도(M) = 용질의 몰수(mol) / 용액의 부피(L). 단위 mol/L.

예: NaCl 1몰을 녹여 전체 부피 2L → M = 1/2 = 0.5M.

부피는 용액 전체 기준(물만이 아님) — 용질 넣고 최종 부피를 맞춤(메스플라스크로 눈금까지).

희석 공식: M₁V₁ = M₂V₂ (희석 전후 용질 몰수는 안 변함, 부피만 늘어남). 예: 2M 100mL를 0.5M로 → V₂ = 2×100/0.5 = 400mL(물 300mL 추가).

화학량론 연결: `HCl + NaOH → NaCl + H₂O`에서 1M HCl 50mL와 반응할 NaOH 몰수 = M×V = 0.05몰(계수 1:1이니 NaOH도 0.05몰). 부피·농도만 재도 화학량론 계산 가능 — 실험실에서 저울 대신 피펫 쓰는 이유.

## 기체 법칙

기체는 분자 간 힘이 거의 무시될 정도로 약해 4개 변수(P 압력, V 부피, T 온도, n 몰수)로 행동 예측.

보일 법칙(T·n 고정): P와 V 반비례. `P₁V₁ = P₂V₂`
샤를 법칙(P·n 고정): V와 T 비례(T는 켈빈). `V₁/T₁ = V₂/T₂`
아보가드로 법칙(P·T 고정): V와 n 비례 — 같은 온도·압력이면 기체 종류 상관없이 같은 부피엔 같은 분자 수.

이상 기체 방정식(셋 통합): `PV = nRT`, R=0.0821 L·atm/(mol·K).

예: 1몰, 0°C(273K), 1atm → V = 1×0.0821×273/1 ≈ 22.4L. "표준상태 기체 1몰 = 22.4L"의 근거.

분자 운동론 설명: 기체 분자가 벽에 부딪혀 압력 생성. 온도↑→분자 속도↑→충돌 세짐/잦아짐→압력↑(부피 고정 시). 부피↓→분자가 좁은 공간에 갇힘→충돌 빈도↑→압력↑(보일 법칙).

## 열화학

화학 결합은 에너지를 저장. 결합을 끊는 데는 에너지 필요(흡수), 결합이 생길 땐 에너지 방출. 반응의 발열/흡열은 이 둘의 순수 차이.

발열 반응(Exothermic): 방출>흡수, 열을 주변에 내보냄(주변 온도↑). 예: 연소, 중화 반응 대부분.
흡열 반응(Endothermic): 흡수>방출, 주변에서 열을 뺏음(주변 온도↓). 예: 얼음 녹기, 광합성, 냉각팩(질산암모늄 용해).

발열: 생성물 에너지가 반응물보다 낮음 → 차이만큼 열 방출.
흡열: 생성물 에너지가 반응물보다 높음 → 차이만큼 열 흡수.

엔탈피(H): 물질이 갖는 에너지량. 반응 엔탈피 변화 ΔH. ΔH<0 발열, ΔH>0 흡열.

활성화 에너지(Ea)와 구분: Ea는 반응이 시작되려면 넘어야 하는 언덕(속도 관련). ΔH는 반응 끝나고 최종 에너지 차이(발열/흡열 여부). 발열 반응도 Ea는 있음 — 산불도 불씨(Ea)는 필요.
