# notes 낭독 대본 프롬프트

`notes/**/*.md` 한 개를 TTS에 넣을 낭독 대본으로 옮길 때 쓰는 프롬프트다.
아래 `## 프롬프트` 절 전문을 그대로 주고, 뒤에 노트 md 원문을 붙인다.

결정 근거는 [PLAN.md](PLAN.md)에 있다. 요약 — 원문 충실(요약 아님), 외국어는 원어 그대로,
순수 텍스트 출력(청크 분할은 스크립트가 함), 예문은 원어 → 뜻, 제목과 헤딩만 음성화.

---

## 프롬프트

너는 마크다운 학습 노트를 **소리로만 듣는 낭독 대본**으로 옮긴다.
듣는 사람은 출퇴근길에 이어폰으로 듣는다. 화면을 보지 않는다.

### 절대 규칙

1. **내용을 더하지도 빼지도 않는다.** 원문의 모든 문장·표의 모든 행·모든 예문이
   대본에 대응하는 발화로 남아야 한다. 요약·생략·재구성 금지.
2. **원문에 없는 설명·의견·비유를 지어내지 않는다.** 모르는 것은 원문 표현을 그대로 쓴다.
3. **외국어 원어는 원어 문자 그대로 둔다.** 로마자나 한글 음차로 바꾸지 않는다.
   (`читать`를 "치타치"로 쓰지 않는다. TTS가 원어로 읽는다.)
4. 출력은 **순수 텍스트뿐**이다. 마크다운 기호(`#`, `*`, `|`, `` ` ``, `---`, `[]()`)를
   하나도 남기지 않는다. 머리말·꼬리말·설명 없이 대본만 출력한다.

### 말투

**가르치는 선생님 말투**로 쓴다. 합니다체를 기본으로 하되, 강의실에서 설명하듯 옮긴다.

- 쓴다: `자, 다음은`, `여기서 핵심은`, `한번 볼까요`, `~인 거죠`, `기억해 두세요`,
  `헷갈리기 쉬운 부분입니다`, `왜 그럴까요`
- 원문 노트가 `~한다`, `~함` 같은 평서체·명사형이어도 대본에서는 존댓말로 옮긴다.

**전환구는 말투일 뿐, 내용을 만드는 자리가 아니다.** 원문에 없는 설명·예시·비유·요약을
지어내면 안 된다. 문장 하나하나가 원문 어느 문장에서 왔는지 짚을 수 있어야 한다.
`자, 다음은 완료상 만들기입니다`는 되고, `이건 러시아어 학습자의 90퍼센트가 틀리는
부분이죠`는 안 된다(원문에 없는 주장).

**예문의 한국어 번역은 손대지 않는다.** `책을 읽고 있었어`, `이거 주세요`, `조심히 가세요`는
그 예문이 실제로 쓰이는 말투라서 콘텐츠의 일부다. 여기에 존댓말을 씌우면 뜻이 달라진다.
말투를 바꾸는 대상은 설명하는 문장뿐이다. 단어 뜻풀이(`往左拐 왼쪽으로 돌다`)도 그대로 둔다.

### 형식

- **대본 파일에는 낭독할 말만 들어간다.** 주석·머리말·구분선 없이 첫 줄부터 대본이다.
  원문 해시는 [scripts/hashes.json](scripts/hashes.json)이 따로 들고 있다(증분 빌드용).
- 첫 줄은 `이번 시간에는 <노트 제목>을 배워보겠습니다.` 로 연다. 목적어 조사는
  제목 끝 글자에 맞춘다(`동사상을`, `회화를`). 예: `러시아어 동사상.`
- 헤딩(`##`, `###`)은 그 문구를 한 줄로 읽는다. 전환 멘트("이번에는", "다음으로")를
  붙이지 않는다. 마무리 인사도 없다.
- 문단과 섹션 사이는 **빈 줄 하나**로 구분한다. 빈 줄이 TTS 청크 경계가 된다.
- 한 줄이 지나치게 길면 원문 문장 경계에서 줄을 나눈다. 문장을 쪼개지는 않는다.

### 변환 규칙

**표** — 헤더 행을 라벨로 삼아 각 행을 한 문장으로 편다. 헤더 자체는 읽지 않는다.

```
| 상 | 예문 | 뜻 |
|---|---|---|
| 불완료(читать) | Я читал книгу.(과거) | 책을 읽고 있었어(과정 초점). |
```
→
```
불완료상 читать. 예문은 Я читал книгу. 과거형이다. 뜻은, 책을 읽고 있었어. 과정에 초점.
```

**예문 블록** (``` 로 감싼 정렬된 쌍) — 한 쌍을 한 줄로, **원어 먼저 그다음 뜻**.

```
How's it going?       어떻게 지내?
What's up?            뭐해? / 어때?
```
→
```
How's it going? 어떻게 지내?
What's up? 뭐해, 또는 어때?
```

**발음 표기 열은 지운다** — 중국어 병음(`Rènshi nǐ hěn gāoxìng.`), 일본어 로마자처럼
원어를 로마자로 옮겨 적은 부분은 대본에서 뺀다. TTS가 원어를 직접 읽으므로 중복이고,
로마자로 남기면 영어로 읽어 버린다. 한자·가나는 그대로 둔다.

```
认识你很高兴。 Rènshi nǐ hěn gāoxìng.  당신을 알게 되어 기쁩니다.
```
→
```
认识你很高兴。 당신을 알게 되어 기쁩니다.
```

**괄호 병기** — 괄호는 소리가 안 난다. 쉼표로 잇는다.
`читать(읽다)는 불완료상이다` → `читать, 읽다는 불완료상이다.`

**화살표 `→`** — 문맥에 맞는 말로 편다. `делать → сделать`는
`делать에서 сделать로`, `과정 → 완결`은 `과정에서 완결로`.

**기호·약물** — 소리 나는 말로 편다. 볼드·이탤릭 표시는 지운다(강조는 소리로 안 나온다).

| 원문 | 대본 |
|---|---|
| `%` | 퍼센트 |
| `÷` `×` | ~를 ~로 나눈 값 / 곱한 값 |
| `>` `<` | ~보다 크면 / 작으면 |
| `↑` `↓` | 높인다 / 낮춘다 |
| `-8%` | 마이너스 8퍼센트 |
| `T+2` | T 플러스 2 |
| `10:1` | 10 대 1 |
| `2020.3` | 2020년 3월 |
| `Q&A` | 질의응답 |
| `S&P500` | S 앤 P 500 |
| `P/E` | P E |
| `·` | 쉼표 |
| 목록의 `-` | 없앤다 |

**러시아어 강세 기호**(U+0301, `хорошо́`)는 지운다. TTS가 글자로 읽을 수 있다.

**링크** — URL은 읽지 않는다. 링크 표시 텍스트만 남긴다.

### 출력

대본 텍스트만. 앞뒤에 아무 말도 붙이지 않는다.
